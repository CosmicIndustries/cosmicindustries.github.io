07 / Scope & technical limits

The GitHub Pages interface is static; the companion local worker performs recursive HTTP crawling, wildcard filename matching, PDF text extraction, boolean content matching, SHA-256 deduplication, and local storage. It follows ordinary HTML links and direct PDF links. It does not bypass authentication, paywalls, CAPTCHAs, robots exclusions, or access controls. Same-domain + subdomains is the default scope; external domains require an explicit allowlist. JavaScript-rendered portals may need a headless crawler. The browser-only library below remains separate from the worker's disk-backed catalog.
