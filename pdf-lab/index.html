Scope & technical limits

This GitHub Pages app is a static browser application. It does not run ffuf, feroxbuster, Katana, or server-side crawlers. Browser security prevents it from recursively crawling arbitrary domains or downloading cross-origin PDFs in the background. Search-engine discovery, URL collection, and local file storage work without a backend. For authorized domain-wide crawling, pair this interface with a local worker running tools such as Katana, ffuf, or Feroxbuster and import its URL results here.
