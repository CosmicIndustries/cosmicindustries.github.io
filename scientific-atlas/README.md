# Scientific Data Atlas

Public seed corpus for recovering overlooked, changed, endangered, missing, and debunked scientific evidence.

## Snapshot

- **21 records**
- **10 STRONG-evidence records**
- **12 loss-sensitive / changed / archived / partial records**
- **4 falsification or research-integrity records**
- Snapshot: **2026-09-21**

## Purpose

The atlas tracks scientific evidence that is easy to lose, difficult to access, incompletely digitized, historically misinterpreted, or useful as a falsification/control case.

A vanished URL is **not** treated as a vanished dataset.

## Provenance states

Examples include `CURRENT_VERSIONED`, `CHANGED`, `MOVED`, `MIGRATING`, `PARTIAL`, `AT_RISK`, `ARCHIVED`, `RETIRED`, `RECOVERED`, and `UNRESOLVED_CLAIM`.

## Anti-bunk rules

1. Primary measurements outrank summaries when both are available.
2. Discovery potential is a **triage field**, not a truth score.
3. Claims and evidence are kept separate.
4. Historical failures are preserved as control cases rather than erased.
5. Source changes are recorded instead of silently overwriting history.
6. Missing access is not interpreted as suppression without evidence.
